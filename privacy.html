Clipper GTA - Privacy Policy

Clipper GTA runs only on its owner's computer. It uses TikTok Login Kit and the Content Posting API solely to publish videos to the owner's own TikTok account.

Data used: the TikTok access token and basic profile information (display name) returned by TikTok.

Storage: this data is stored locally on the owner's computer only. It is never sold, shared, or sent to any third party.

Removal: the owner can disconnect the TikTok account at any time from the app or from TikTok's settings, which deletes the stored token.

Contact: the owner of this GitHub account (Max041221).
